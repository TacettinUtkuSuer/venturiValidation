VenturiFlow — Ortak Kayıt Anahtarı

Bu sayfa GitHub anahtarınızı bu tarayıcıda ortak parolayla şifreler. Anahtar ve parola hiçbir yere gönderilmez; yalnızca depo erişimini test etmek için GitHub'a tek bir istek yapılır.

1 · Hazırlık
  1. GitHub'da veri deposunu açın (ör. venturiValidation-data).
  2. Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  3. Repository access: Only select repositories → yalnızca veri deposu.
  4. Permissions → Repository permissions → Contents: Read and write. Başka izin vermeyin.
2 · Şifrele
3 · Uygulamaya ekle

Aşağıdaki içerik uygulama deposundaki js/sync-config.js dosyasının yeni hâlidir. İçinde anahtarın kendisi yoktur, sadece şifreli hâli vardır.

  1. GitHub'da uygulama deposunda js/sync-config.js dosyasını açın → ✏️ Edit.
  2. İçeriği tamamen yukarıdakiyle değiştirin → Commit changes.
  3. Birkaç dakika sonra uygulamayı açın; ilk açılışta ortak parola sorulur.
